# Canvas YouTube Transcript

Obsidian Canvas의 YouTube 카드에서 전체 자막을 새 텍스트 카드 하나로 가져오는 데스크톱 플러그인입니다.

## 사용 방법

1. Canvas에서 YouTube 링크 카드를 우클릭합니다.
2. **YouTube 자막 추출**을 선택합니다.
3. 자막이 여러 개면 언어와 수동/자동 생성 자막을 고릅니다.
4. 반투명 미리보기를 원하는 위치로 옮긴 뒤 Canvas를 클릭하면 전체 자막 카드가 만들어집니다. `Esc`를 누르면 취소됩니다.

명령 팔레트의 **선택한 YouTube Canvas 카드의 자막 추출**에서도 같은 기능을 사용할 수 있습니다.

## 범위

- 실행할 때마다 자막 카드 한 개를 새로 만듭니다.
- 원본 카드와 Markdown 파일은 바꾸지 않습니다.
- 공개 YouTube 자막을 로그인 없이 가져옵니다.
- 데스크톱 Obsidian 전용입니다.

## 설치

BRAT에서 `tlatndms2-droid/canvas-youtube-transcript` 저장소를 추가해 설치합니다.
